# Legacy QPoints Conversion Flow

This directory contains the archived bash-based checkpoint conversion flow that
predated the canonical `.gem`-based `qflex qpoints convert-single` path.

Archived files:

- `run_all.sh`
- `run_all_multi_snapshot.sh`
- `gen_snapshot.sh`
- `scripts/qflex/run_qemu_emu.sh`
- `scripts/qflex/convert.sh`

These scripts are preserved only for historical reference. They are not part
of the supported checkpoint-conversion contract anymore.
